Never derive production canonical from VERCEL_URL, VERCEL_BRANCH_URL or VERCEL_PROJECT_PRODUCTION_URL. ## Build/runtime assumptions

- Verified JSON and evidence are committed; no source scraping/cache directory/Windows shell/proxy needed to build or render the app.
- `scripts/fetch-sources.ps1` is a manual source-maintenance tool with configurable localhost proxy; it is not a Vercel build hook. `CHECK_BASE_URL` localhost references belong to audit tools only.
- `next/font/google` requires Google Fonts access during a fresh build; generated fonts are served from the deployment at runtime. CI must have network access. Offline builds are not guaranteed.
- OG image is generated by the built-in Next image route, using project code; no external image service, account or API key.
- Shared policies and all valid discovery pages are statically generated; Finder URL state hydrates client code without database/backend dependencies.
- npm lint is an explicit gate; Next build alone is not a replacement for it.
